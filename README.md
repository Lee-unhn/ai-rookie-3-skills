# AI 新秀第三期 · AI 產業應用｜班級 skill 庫

這個 repo 收集 7 組在課堂上寫的 skill。每一組把自己的工作說明寫成一份 `SKILL.md`，用 Fork 和 Pull request 送進來。

- 情境：同一家虛構公司「楓渡食集團」的 8 個部門題目。所有公司、人名代號、數字都是虛構的，只供課堂練習。
- 一份 skill＝守則檔＋步驟＋範例＋檢查表：可以重複用，也能交給別人用。
- 同一份內容貼進 Gemini 的 Gem「使用說明」可以直接用；存成 `SKILL.md` 可以給 Claude 用。

## 資料夾

```
skills/
  第0組_範例_回購率報告/SKILL.md   ← 講師範例
  第1組_題目/SKILL.md
  …
  第7組_題目/SKILL.md
```

## 怎麼送進來

照 [CONTRIBUTING.md](CONTRIBUTING.md) 的四個步驟：Fork → 新增檔案 → Commit → Pull request。

## 規則

- 只新增自己組的資料夾，不改這份 README，也不動別組的檔案。
- 不放任何 API key、密碼、真實客戶資料。
- 檔名格式：`skills/第X組_題目/SKILL.md`。

## English

Class repository for the "AI Industry Applications" course (AI Rookie Program, cohort 3). Each of the 7 student groups adds one `SKILL.md` describing a repeatable AI-assisted workflow for a fictional food company. All data is fictional and for classroom practice only. Contributions are made via fork and pull request; see `CONTRIBUTING.md`.
